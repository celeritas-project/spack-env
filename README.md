# Celeritas ExCL spack environments

These are linked into the spack environment dir.
- `include/`: spack config components included by environment files
- `include/ext-*`: system-specific externals
- `include/prefs-*`: build preferences
- `include/reqs-*`: build requirements
- `include/reqs-celer.yaml`: should be identical to
  CELER-SRC/scripts/spack/reqs-celer.yaml
